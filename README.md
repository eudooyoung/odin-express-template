# express template

## About

This template contains basic packages for express application.

## How to use it

After clone this repo, run `npm run install && npx prisma generate`.

## Packages

```
├── express
├── @types/express
├── express-validator

├── eslint
├── @eslint/js
├── typescript-eslint

├── passport

├── prisma

├── typescript

├── supertest
```
